# Data licence

The data files in `site/data/` (`nodes.json`, `edges.json`, `articles.json` and the attribution records in `images.json`) are dedicated to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode). The facts come largely from [Wikidata](https://www.wikidata.org/), which is also CC0.

This does **not** apply to the images in `site/assets/img/`. Each image keeps its own licence and author, as recorded in `site/data/images.json`.

The code (everything else in this repository) is under the MIT licence in [`LICENSE`](LICENSE).
